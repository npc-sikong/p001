# 原型业务检查清单

- 更新：2026-10-13。共 226 组，均在原型上通过。
- 用途：作为后端验收测试的第一批用例。正式实现时，每组检查转为一个或多个集成测试，测试名引用检查编号和对应模块的规则编号。
- 来源：
  - PROF = `scripts/verify-profile.cjs`（资料、IP 服务语言与修改说明同步）
  - V22 = `scripts/verify-v22.cjs`（社交、匹配、房间、活动、权限、原交易回归）
  - MCN = `scripts/verify-mcn.cjs`（公会、保证金、推广、钱包）
  - SVC = `scripts/verify-service.cjs`（周期结算服务与中止争议）
  - INTL = `scripts/verify-intl.cjs`（多语言与多币种）
  - GEN = `scripts/verify-gender.cjs`（性别资料、筛选、匹配、范围与兼容）
  - DEM = `scripts/verify-demands.cjs`（需求贴冻结预算、多申请报价、私聊与选人）
  - REV = `scripts/verify-reviews.cjs`（成交后双向互评与后台治理）
  - ALIGN = `scripts/verify-alignment.cjs`（用户端动作与后台页面对齐、客服工单）
  - UX = `scripts/verify-ux.cjs`（帮助中心、设置中心、协议页、订单详情层级、列表顺序、金额标签）
  - FEED = `scripts/verify-feed.cjs`（首页轮播与后台配置、需求与社区图文流、列表页图文卡片）
  - IMG = `scripts/verify-images.cjs`（帖子图片上传、图片审核与后台开关）
  - CARD = `scripts/verify-cards.cjs`（订单卡片与记录行、用户端不显示分站、中文地点与时区、USDT 标签）
  - AVA = `scripts/verify-avatars.cjs`（默认头像选择、上传头像与图片审核）
