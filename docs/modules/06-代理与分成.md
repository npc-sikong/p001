## 5 主流程

性别关联：公会成员、待签约邀请、普通会员招募和代理 / 推广名单均读取 01 `ID-R016` 的当前会员资料。MCN 管理者可分别筛选成员和本站可邀请对象；个人与机构推广可筛选直推会员。公会本身没有性别，后台机构行只展示管理者性别；“签约服务者 / 招募会员性别”只过滤人物记录，不过滤公会资金。

1. **分站开通：**
   - 创建站点（名称与域名必填）→ 归属 TXT → DNS 指向 → HTTPS → 本站服务与权限健康 → 发布。
   - 更换域名时，验证完成前旧域名继续使用。
   - 部署迁移分五步：预检 → 同版本部署 → 健康检查 → 准备切路由 → 切换后验证；失败保留原映射。
2. **归属：**用户的注册分站单独维护；交易按服务者所在分站归属。迁移只影响之后的交易，订单、账单、分红保留快照。
3. **分站分红：**分站从平台部分中按分站规则分成；规则修改生成新版本，不覆盖历史订单与结算单。站长查看分红明细与结算单，并申请提现（04 提现规则）。
4. **代理：**
   - 服务者通过代理的招募链接或人工指定建立归属。
   - 新订单按分成规则的选择顺序（服务者专属 → 代理专属 → 代理等级默认 → 平台默认）快照比例。
   - 结算后代理佣金进入可提现，代理按等级的结算周期与最低提现申请提现。
5. **公会创建：**会员申请（按配置决定是否需要平台审核、机构材料、最低保证金）→ 正常。同站名称唯一；签约中的服务者需先离会才能创建公会。
6. **招募与签约：**公会统一邀请。
   - 邀请普通会员：本人接受 → 原入驻表单（默认免审）→ 签约确认。
   - 邀请服务者：直接进入签约确认。
   - 邀请 7 天有效，可撤回。签约后，其他公会发给该服务者的待确认邀请自动失效。
7. **公会分成：**签约生效后的新账单按快照比例，从服务者部分提取公会分成。修改比例须双方确认，只影响之后的新账单；总站平台解除签约也只影响之后的新账单。
8. **退出与关闭：**
   - 离会有冷静期，可撤回。
   - 公会退出前检查未完成的签约、履约、售后、赔付与提款。
   - 公会关闭后，机构推广停用。
9. **保证金（可选）：**缴纳单结果未知时只能查询原请求；保障赔付关联原售后记录；退还进入提款流程。
10. **会员推广：**
    - 开启推广，获得邀请码；新会员用邀请码注册，建立唯一直推归因。
    - 直推会员累计充值达到门槛（默认 100 USDT）即为有效推广，达标后保持有效。
    - 有效会员数达到等级门槛即升级。
    - 直推会员用余额消费且服务确认完成后，按当时等级比例生成分红（USDT）。
    - 每天 00:00 汇总入账推广员钱包的可提现余额。
11. **退款冲减：**退款减少分红与佣金基数；已入账的推广分红在下次日结中冲回；公会分成与代理佣金同步冲减，已付部分形成待追回。

## 6 状态机

| 对象 | 状态与迁移 |
| --- | --- |
| 站点 | 草稿 → 开通中（TXT / DNS / HTTPS / 健康）→ 已发布 → 停用；换域名：待验证 → 已切换（失败保留原域名） |
| 公会 | 待审核 / 需补件 / 待缴保证金 → 正常 → 已关闭 |
| 签约 | 待确认 → 生效 → 待双方确认变更 → 生效；生效 → 离会冷静期（可撤回）→ 已结束；平台解除 → 已结束 |
| 推广关系 | 待达标 → 有效推广；→ 已到期；→ 人工失效 |
| 佣金 / 分站分红 / 公会分成 / 推广分红 | 待结算 → 可提现（或已入账）→ 已提现；售后中为保全中；退款后冲减或冲回 |

## 7 业务规则

- `PT-R001` 服务者同一时间只能有一个生效的公会签约；公会管理者不能被其他公会招募。
- `PT-R002` 公会分成比例在新账单创建时快照；默认比例与上限由后台配置；三方毛分账守恒，公会分成从服务者部分提取。
- `PT-R003` 公会准入条件（平台审核、机构材料、已认证服务者、最低保证金）均可在后台关闭；关闭后自愿缴纳的保证金照常记录。
- `PT-R004` 保证金与收益资金分开管理；保障赔付须关联原售后记录，冻结后赔付或驳回，不重复修改原退款。
- `PT-R005` 只计算直推关系，没有多级推广；不能推广自己；已有会员不能被重新归因；不覆盖原有站点或代理归属。
- `PT-R006` 有效推广 = 直推会员累计已到账充值 ≥ 后台门槛（USDT），并满足已开启的核验条件；达标后保持有效。
- `PT-R007` 推广等级只按有效会员数升级；比例在消费确认时冻结，升级不回写已产生的分红。
- `PT-R008` 计入分红的消费默认“仅余额消费”，后台可改为“全部服务消费”，该口径下可开启 VIP 计入。口径和推广资格在消费确认时判定，之后修改不追溯。
- `PT-R009` 分红由平台收入承担。比例高于平台扣除分站后的留存比例时，平台会倒贴，后台分账表须以红字提示。
- `PT-R010` 推广分红每天 00:00 结算前一天的数据；售后中的订单暂缓结算；同一日期不重复入账。
- `PT-R011` 推广关系到期后，之后的消费不再产生分红；已产生的分红照常结算。
- `PT-R012` 站长只读本站；规则、等级、结算与出款只能由总站操作。
- `PT-R013` 代理分成：服务者、代理、平台使用同一分配基数，比例合计 100%；只采用一个有效规则（服务者专属 → 代理专属 → 代理等级默认 → 平台默认）。代理佣金与平台收入都从同一基数分配，不在服务者净收益上重复扣除；晋级只改变新订单规则，不重算历史佣金。
- `PT-R014` 交易按服务者所在分站归属；跨站消费不把用户的全部资料开放给交易分站；归属迁移不改变已成交订单、账单与分红的分站快照。
- `PT-R015` 分站分红从平台部分中分成，规则版本化；VIP 是否参与为独立开关（默认不参与）；正式比例与基数待确认。
- `PT-R016` 域名全平台唯一，不接受协议、路径、端口、通配、IP 或内部地址；发布前须完成归属与证书验证；切换失败保留原映射。
- `PT-R017` 币种：
  - 首期佣金、分站分红、公会分成、推广门槛与分红都以 USDT 计算；代理、站长、公会提现以 USDT 出款。
  - 以后启用其他定价币种时，分站定价币种由总站在“币种与汇率”中设置（04 `TF-R025`）；佣金、分站分红、公会分成同时记录定价币种金额与按支付快照折算的 USDT 金额。
- `PT-R018` 多语言：分站可以继承平台语言配置或独立配置开放语言、默认语言、备用语言与展示时区（07 `PF-R015`），首期只能在中文与英语中选择；站长只读本站语言与币种设置。

- `PT-R019` 公会招募 / 签约、代理、推广的性别查询与原站点、签约排他、账号状态、邀请有效期和推广范围同时生效。筛选仅改变当前展示名单，不增设性别门槛，不改变有效会员总数、推广等级、分红、保证金或历史财务快照。机构推广的性别展示指管理者资料，直推会员筛选指被推广会员资料。

## 8 异常与边界

- 邀请过期、对方已签约其他公会、招募已暂停、跨站招募时，明确拒绝。
- 公会存在未结清事项时不能退出；关闭后不能恢复机构推广。
- 存储失败时，新公会、受邀入驻、推广注册都整体回滚。
- 域名验证失败或证书未就绪时，站点不能发布。

## 9 资金与证据影响

- 代理佣金、分站分红、公会分成、推广分红、保证金都是独立科目，进入 04 模块的账务与对账。
- 推广分红入账会员钱包（可提现）；代理、分站、公会收益走各自的提现流程。
