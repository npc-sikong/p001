# 07 公共能力

- 规则编号前缀：`PF-`
- 状态：**V1.0 已评审**（2026-10-06，项目负责人）。已与原型 V23 的用户端、后台页面及《技术架构与技术选型》核对；待定参数仍按 D 编号保持关闭。
- 代码模块：`platform`（不依赖任何业务模块；业务模块通过接口调用它，或实现它定义的 SPI）
- 依赖的待定参数：D01（数据驻留、录音与证据政策、上线语言）、D09（UI 重设计工具）

| --- | --- |

## 2 能力与边界

| 能力 | 提供方式 | 边界 |
| --- | --- | --- |
| 消息 | 会话由业务对象引用（订单、咨询、交流），只有参与人可读写 | 后台只看索引；举报案件中由授权岗位核查证据 |
| 通知 | 业务模块调用通知接口；模板按语言维护；投递失败可重试，已成功的不重复发送 | 模板变量须与原文一致 |
| 待办 | 各模块实现 `TodoSource`，消息中心汇总并计入未读角标 | 待办只是入口，动作仍由业务模块校验 |
| 语音 | `RtcProvider` 签发令牌、接收回调，记录连接区间 | 默认不录音；连接记录不等于服务质量证明 |
| 文件 | 预签名直传对象存储；证据桶私有，短时效签名访问 | 校验类型与大小；去除图片位置信息 |
| 配置 | 版本化配置项，修改须填写依据；配置项有“待定”状态 | 依赖待定参数的功能默认关闭 |
| 多语言 | 语言、分站配置、词条与译文、业务内容译文、通知模板、语言包版本 | 只翻译界面与运营内容，不翻译用户发布的内容 |
| 本地格式 | 按界面语言格式化数字、金额、日期；按展示时区显示时间 | 不换算币种，不修改订单时区 |
| 审计 | 只能追加：操作人、动作、对象、依据、前后值、请求号 | 不可修改或删除 |

## 4 数据与字段

| 对象 | 关键字段 |
| --- | --- |
| conversation / message | 关联对象（订单 / 咨询 / 交流）、参与人、类型（文字 / 图片 / 语音）、内容或文件 ID、已读、时间（按月分区） |
| notification / template | 接收人、模板、语言、变量、渠道、状态（待发送 / 成功 / 失败）、重试次数、去重键；模板按语言维护，变量须与中文原文一致 |
| rtc_session / rtc_event | 房间、参与人、令牌有效期；事件：加入、离开、断线、恢复（含时间） |
| file_object | 存储桶、路径、类型、大小、哈希、用途（头像 / 声音 / 证据 / 商品证明）、可见范围、保留期限 |
| locale | code（BCP 47，如 zh-CN、en-US、ar-SA）、中文名、自称、文字方向（ltr / rtl）、启用状态、排序 |
| site_language_config | scope（平台 / 分站）、mode（继承平台 / 独立配置）、supported、default、fallback、autoDetect、userSwitch、displayTimezone、clock（12 / 24）、dateStyle |
| i18n_entry / translation | 词条 ID、类别（界面 / 业务内容）、分组、中文原文、原文版本、是否必须完整翻译、关联对象；译文按语言保存，含 text、sourceVersion、状态（待翻译 / 原文已更新 / 变量不一致 / 已完成） |

## 5 主流程

1. **消息：**发送前校验参与人与拉黑关系 → 落库 → 通过 WebSocket 推送；离线消息和未读数从数据库计算。
2. **通知：**业务事件触发通知 → 按接收人的界面语言选择模板，缺失时使用分站备用语言 → 投递 → 失败可重试；同一去重键不重复发送。
3. **语音：**业务模块请求房间令牌（校验订单关系或房间成员身份）→ 客户端加入 → 回调写入连接事件 → 生成连接区间。
4. **文件：**申请上传凭证 → 浏览器直传 → 服务端校验并登记 → 业务对象引用文件 ID。
5. **多语言发布：**
   - 启用语言 → 维护界面词条与业务内容译文（可导出 / 导入翻译文件）→ 配置平台与分站的开放语言 → 预览（含右向左布局）。
   - 发布前检查必要内容、变量、默认语言与时区，通过后由管理员发布语言包。
   - 出错时可回滚到历史语言包。
6. **配置：**后台修改配置 → 填写依据 → 生成新版本；成交时由业务模块读取并快照。

## 6 业务规则

**通用能力**

- `PF-R001` 后台运营只能看咨询与会话的索引和数量；正文仅在举报案件中由授权岗位核查。
- `PF-R002` 通知同一去重键只成功发送一次；失败重试保留次数与结果。
- `PF-R003` 语音默认不录音；连接、断开、恢复事件只作为计费与售后的参考证据。
- `PF-R004` 上传文件须校验类型与大小，证据文件私有，访问须使用短时效签名；保存期限按配置。
- `PF-R005` 配置项为“待定”时，依赖它的功能不可启用；代码不得写默认值。
- `PF-R006` 时间统一存 UTC，按分站或订单的业务时区计算业务日期；业务代码通过注入的时钟取时间。
- `PF-R007` 测试与预发环境可以推进业务时钟（用于验证周期结算与 24 小时时限）；生产环境禁用。
- `PF-R008` 后端返回错误码与参数，不返回某种语言的句子；前端按界面语言翻译。
- `PF-R009` 统计只用服务端可信事件，按幂等键去重；没有发生的事件显示 0，不用示例数据填充；漏斗按顺序计算，每步显示分母；金额按币种分别统计。
- `PF-R010` 每个页面提供业务 / 字段说明（用途、角色、流程、字段、关联页面）；说明不增加权限，动作仍需鉴权。
- `PF-R011` 审计日志只能追加；资金、权限、配置、审核、语言包发布与回滚动作必须写入。

**多语言**

- `PF-R012` 用户端界面语言的确定顺序：用户手动选择（分站允许切换时）→ 账号保存的语言 → 浏览器偏好（分站开启自动识别时）→ 分站默认语言 → 中文兜底。只能使用分站已开放且已发布的语言；首期只开放中文（zh-CN）与英语（en-US）。
- `PF-R013` 切换界面语言只改变界面文字与数字、日期格式，不改变账号身份、所属站点、会员权益、订单币种与金额、订单时区。
- `PF-R014` 中文（zh-CN）是原文与兜底语言，不能停用。首期只启用中文与英语，其他预置语言保留为草稿，补齐译文并按 D01 确认后才能启用。语言可设置文字方向，界面预留右向左（如阿拉伯语）的整体镜像能力。仍被平台或分站使用的语言不能停用。
- `PF-R015` 分站语言配置可“继承平台”或“独立配置”：开放语言、默认语言（须在开放语言内）、普通文案缺失时的备用语言（须已开放）、用户默认展示时区、12 / 24 小时制、日期格式、首次访问自动识别、允许用户切换。
- `PF-R016` 词条与业务内容按中文原文的版本管理：原文更新后，旧译文标记为“原文已更新”，不再作为有效译文；译文中的变量（如 `{订单编号}`）必须与原文完全一致，否则不能保存。
- `PF-R017` 展示时按“当前语言 → 备用语言 → 默认语言 → 中文”选择有效译文。标为“必须完整翻译”的内容（交易说明、价格说明、通知必备内容）缺失时，阻止该语言的语言包发布。
- `PF-R018` 业务内容多语言覆盖商品名称与规格、购买规则、服务模板说明、会员权益与价格说明、站点介绍、论坛板块等。翻译编辑不覆盖历史订单快照；编辑中文商品名称或规格时，同步对应商品资料。
- `PF-R019` 语言包发布：保存译文不会立即影响线上展示；发布前须通过完整性检查；可以回滚到历史版本（回滚生成新的发布记录）。原型中由同一管理员完成编辑、检查、发布与回滚，不增加其他审批人。
- `PF-R020` 后台语言由管理员自己切换，不影响任何用户的语言偏好。用户发布的内容、证据和处理理由不参与翻译。

**金额与币种展示**

- `PF-R021` 金额按界面语言的本地格式显示（千分位、小数点），始终带币种代码（首期为 USDT）；不同币种不在同一数字里相加。币种、汇率与快照规则见 04 `TF-R021`—`TF-R029`。

## 7 异常与边界

- WebSocket 断线自动重连，期间的消息从数据库补齐。
- RTC 回调丢失时，以服务端查询为准、客户端上报为辅，并标记为“不完整”。
- iOS Safari 需用户点击后才能开启音频，锁屏或切到后台会中断，需提示并自动重连。
- 语言包检查不通过时不能发布，线上继续使用当前版本。

## 9 验收场景

- 原型检查（18 组，清单见 `docs/acceptance/原型业务检查清单.md`）：V22-01、V22-12、V22-16、V22-17、V22-19、V22-22、MCN-18、MCN-22、MCN-25、MCN-26、MCN-36、SVC-09、INTL-01、INTL-02、INTL-03、INTL-06、INTL-07、INTL-08。
- Given 一条通知第一次发送失败，When 重试成功，Then 只记录一次成功，不重复送达。
- Given 配置项“充值网络”为待定，When 会员发起充值，Then 功能不可用并提示待开放。
- Given 英文译文缺少 `{金额}` 变量，When 保存译文，Then 拒绝并提示变量必须与原文一致。

## 10 待定参数

- D01：数据驻留区域、录音与证据政策、内容审核要求、中文与英语以外的上线语言。
- D09：UI 重设计工具与交付方式。
- 不得由研发或 AI 代填。首期只开放中文与英语（原型用户端词条完整提供这两种语言）；其他预置语言为草稿。
