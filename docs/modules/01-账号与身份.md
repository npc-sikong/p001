## 5 主流程

1. **注册：**选择站点 → 填写昵称、账号 → 确认成年与协议 → 可选填写邀请码 → 创建用户。
   - 邀请码有效时，按 06 模块建立直推归因。
   - 界面语言按“手动选择 → 浏览器偏好 → 分站默认语言”确定（07 `PF-R012`）。
2. **入驻：**用户提交申请 → 审核中 → 通过 / 需补件 / 未通过。
   - 通过后账号追加服务者能力，初始为暂停接单；完善商品与档期后可接单。
   - 公会受邀入驻的路径见 06 模块。
3. **材料：**服务者提交新版本 → 后台审核 → 通过后替换公开版本；退回后可修订重提。
4. **VIP：**生成 VIP 订单（首期以 USDT 计价）→ 余额支付 → 授予权益并保存权益快照 → 到期后进入只读收尾。
5. **后台登录：**账号与口令（生产环境增加 TOTP）→ 30 分钟会话 → 总站可撤销会话。后台语言单独切换，不改变用户的语言偏好。

## 6 状态机

| 对象 | 状态与迁移 |
| --- | --- |
| 入驻申请 | 未申请 → 审核中 → 通过 / 需补件（→ 审核中）/ 未通过（→ 重新提交 → 审核中） |
| 服务者接单状态 | 可接单 ⇄ 暂停接单；认证过期后为资格失效 |
| 材料版本 | 待审核 → 已通过（替换公开版本）/ 已退回（可修订重提）；已处理的版本不能再次审核 |
| VIP 订单 | 待支付 → 已支付 / 支付失败 / 结果未知（只能查询原请求）→ 退款处理中 → 已退款 |
| 后台会话 | 有效 → 过期 / 已撤销 |

## 7 业务规则

- `ID-R001` 每个账号默认是用户。服务者认证通过后追加服务者能力。个人中心切页只改变功能展示，不改变身份、认证状态和权益。
- `ID-R002` 注册须选择站点，昵称 1—20 字，账号唯一，并确认成年与协议。账号异常或未完成成年校验时，不能购买，也不能使用社交功能。
- `ID-R003` 服务者认证过期后，拒绝新增购买其服务；历史订单照常处理。
- `ID-R004` 材料按版本管理：待审或退回的版本不影响已审公开版本，只有审核通过才替换。
- `ID-R005` 月度 VIP 为单一方案，权益在购买时快照，之后修改方案不影响已购权益。
- `ID-R006` 需要有效 VIP 的动作：咨询、关注、立即找人、组队房（创建、加入、邀请、发言、麦位）、发帖与回复、需求发布；服务者也适用。普通用户可以浏览、试听、查看活动和直接购买服务。
- `ID-R007` VIP 到期后，可以查看历史、结束咨询、退出或下麦、取消关注、关闭提醒、拉黑和举报，不能新增社交互动。
- `ID-R008` 服务者通过认证不自动获得 VIP。
- `ID-R009` 总站管理员唯一，不能停用、删除或降权。站长只能只读本站并提交协助，不能审核、关闭、退款裁决或跨站。
- `ID-R010` 后台会话 30 分钟；切换账号须重新登录；总站可撤销某账号的现存会话，撤销后该会话不能继续管理。
- `ID-R011` 每个动作都校验岗位权限、数据范围和对象归属；申请、审核、执行分权（资金动作见 04，售后见 05）。
- `ID-R012` 禁止购买自己提供的服务，禁止给自己评价。
- `ID-R013` 用户等级与服务者等级只用于展示，由总站人工指定，不自动升级，不联动 VIP 权益、价格折扣、接单资格或分成；停用等级时前台回退到基础等级，已有订单不受影响。
- `ID-R014` 界面语言偏好、展示时区与服务者可提供服务的语言分开保存。切换界面语言不改变账号身份、所属站点和会员权益；只能选择本站已发布的语言，首期为中文与英语（07 `PF-R013`）。
- `ID-R015` VIP 价格首期以 USDT 定价；以后启用其他定价币种时，按分站定价币种配置价格表，支付时按当时汇率折算为 USDT 并保存（04 `TF-R021`、`TF-R022`）。价格待 D06 确认。

## 8 异常与边界

- 邀请码无效、暂停或跨站时，明确提示，注册仍可在不归因的情况下继续。
- 材料文件超限、格式错误或无法解码时拒绝提交；保存失败整体回滚。
- VIP 支付结果未知时，只能查询原请求；重复的成功回执不重复授权。
- 选择本站未发布的界面语言时拒绝，并保持原语言。

## 9 资金与证据影响

- VIP 订单的收款与退款走 04 模块的账务；VIP 购买是否计入推广分红，由 06 模块配置决定。
- 入驻材料与 KYC 结果仅授权岗位可见。

## 12 通知、待办与审计

- **审计：**登录、权限变更、会话撤销、等级指定、审核结论（必须填写依据）。
