## 2 角色与权限

- **服务者：**维护本人商品与档期，提交履约事实（摘要与证据），不能确认自己提供的订单。
- **购买方：**预约、改期、取消单次预约、确认完成或提出问题、试聊换人、评价。
- **总站：**审核商品、模板、订阅内容；维护服务分类；暂停展示。站长只读本站。

## 5 主流程

性别取自 01 `ID-R016` 的关联会员资料。首页、服务者卡片、详情展示当前值；发现、关注与最近服务可按性别筛选，继续与服务分类、地区、状态、档期等原条件求交集。立即找人保存服务者性别偏好，搜索、候选响应、选定和预约均复核；后台匹配列表可按这项已保存偏好查询。

1. **上架：**服务者基于模板创建商品 → 审核 → 已上架。修改价格、规格或说明后重新审核；已成交订单保留原规则、价格与币种快照。
2. **预约校验：**
   - 每个服务日在所选时段必须是开放且未被占用的档期。
   - 开始时间至少提前 bookingLeadHours，且在 bookingHorizon 天内。
   - 整个服务期须在已开放的档期窗口内（原型为 14 天）。
3. **履约：**服务者在服务日提交履约摘要与证据 → 购买方确认完成或提出问题。周期结算订单在周期到期时由系统自动确认（见 04 `TF-R010`）。
4. **改期 / 取消单次预约：**
   - 改期：在同一账单的有效区间内改到开放档期，释放原时段，额度不增加。
   - 取消单次预约：满足取消窗口时可取消并保留额度，退款需另行申请（见 05）。
5. **试聊换人：**正式履约开始前可以试聊并申请换人。每个主订单最多一次成功换人；候选失效、无匹配或替换失败不扣额度。
6. **服务中页面：**模拟接通、断线、重连、结束，只记录连接区间，不自动确认收益。
7. **评价：**订单完成后购买方评价；后台可以查看和处理评价。

| 对象 | 状态与迁移 |
| --- | --- |
| 商品 | 草稿 → 待审核 → 已上架 / 需修改（→ 待审核）/ 未通过；已上架 → 已下架 |
| 服务分类 | 启用 ⇄ 停用；父类停用不改写子类的独立状态 |
| 履约单元 | 待履约 → 待确认（服务者提交）→ 已确认（购买方确认或周期到期自动确认）；待履约 → 已取消（取消单次预约或开始前取消订单）/ 已退款（中止退款） |
| 换人 | 待接受 → 成功 / 失败 / 失效 |

## 7 业务规则

- `CT-R001` 商品展示服务内容、价格（含币种）、单次时长、可预约时间、下单规则，以及试聊、换人、取消、退款和中止规则。日、周商品说明每期次数或时长。
- `CT-R002` 价格必须与所选次数、时长、附加要求同时显示；详情页、确认页和摘要使用同一个已审规格、计价单位和币种。
- `CT-R003` 服务额度不能被解释为全天无限陪伴；每期次数 ≤ 每日额度 × 服务天数。
- `CT-R004` 预约面板每天一次；同一服务者同一时段不能重复占用（数据库用排他约束防止重叠）。
- `CT-R005` 服务者只能提交本人的到场、试聊、履约和证据事实，无权确认自己提供的订单完成。
- `CT-R006` 按“整期目标验收”的服务，在全部单元确认前不开放结算；其结算周期应等于服务期。
- `CT-R007` 每个主订单最多一次成功换人；换人与续期都不重置该权益。正式服务开始后的换人进入售后处理。
- `CT-R008` 服务中的连接记录与订单履约分开：通话结束不自动确认收益；不默认录音。
- `CT-R009` 中止申请处理期间，该订单的提交履约、确认、改期、取消单次预约等操作暂停（见 05）。
- `CT-R010` 实物商品：
  - 生成待支付单即占用库存；支付结果未知时保留占用并查询原请求；取消只释放一次。
  - 确认收货后进入 7 天演示售后窗口。
  - 已发货的退货退款，核实收回后恢复库存一次。
- `CT-R011` 服务者订阅：
  - 按业务时区计算自然月；主动付款续费，不自动扣款；到期重新锁定专享内容。
  - 主动退订时，当前期按剩余时间比例退款，未开始的期全额退款。
- `CT-R012` 服务分类固定三级：大类 → 线上 / 线下 → 具体服务。停用会阻止新购买、匹配与续期；已付款但尚未匹配的可以原款关闭退款；已成交的额度、履约和售后按原快照处理。
- `CT-R013` 暂停展示的服务者退出新的推荐与搜索，历史订单照常处理；认证过期的服务者不能被新购买。
- `CT-R014` 商品名称、规格、购买规则和服务模板说明可以维护多语言（07 业务内容多语言）。必要的交易说明须完整翻译才能在该语言发布；历史订单快照不被翻译修改。服务者可提供服务的语言单独展示，发现页可以按语言筛选。
- `CT-R015` 商品价格以服务者所在分站的定价币种填写和展示，首期为 USDT；修改价格生成新版本；订单保存价格、币种与规则快照（04 `TF-R021`）。分站切换定价币种只影响之后上架的商品与新订单。

- `CT-R016` 性别筛选支持不限、男、女、其他、未填写；“不限”不限制性别，“未填写”单独匹配。匹配创建时保存偏好，重复发起复用已有进行中记录，不覆盖其条件。候选资料变化后不符合偏好时标记失效，人工推荐也遵循同一条件；未选性别的旧匹配继续不限。性别资料变化不阻断已有已付订单的履约、售后与收入结算。

## 8 异常与边界

- 档期被占用或未开放、提前量不足、超出可预约窗口、服务者暂停或资格失效时，预约会被拒绝。
- 商品所在分类已停用时，不能新购买，也不能续期。

## 9 资金与证据影响

- 履约单元金额汇总为账单的已确认金额，是结算依据（04）。
- 履约摘要与证据可作为售后材料（05）。实物运费单独显示并核销，不参与分佣。

## 13 验收场景

- 性别补充：GEN-11—GEN-18、GEN-25（筛选、重置、匹配条件与候选失效、人工推荐、相关页面），对应 `CT-R016`。

- 原型检查（4 组，清单见 `docs/acceptance/原型业务检查清单.md`）：V22-25、V22-26、SVC-01、INTL-04。
- Given 服务者档期 18:00 已被占用，When 另一会员预约同一时段，Then 拒绝。
- Given 订单已成功换人一次，When 再次申请换人，Then 拒绝。
- Given 具体服务已停用，When 会员下单，Then 拒绝；已成交订单照常履约。
