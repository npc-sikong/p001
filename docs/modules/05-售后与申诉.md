# 05 售后与申诉

- 规则编号前缀：`AS-`
- 状态：**V1.0 已评审**（2026-10-06，项目负责人）。已与原型 V23 的用户端、后台页面及《技术架构与技术选型》核对；待定参数仍按 D 编号保持关闭。
- 代码模块：`aftersales`
- 依赖的待定参数：D08（售后时限、复核与申诉费、证据保存）

## 1 目标与范围

| 首期包含 | 后置 |
| --- | --- |
| 服务不达标的中止申请（原因、说明、最多 3 张图片）、处理方式设置（默认直接由平台处理）、公会处理、平台处理与复核、24 小时时限与升级、24 小时异议期、执行（退款退回钱包 / 驳回继续服务）；举报、风险案件、处罚与独立申诉；实物与订阅售后 | 申诉收费（待定）、录音取证（默认不录音）、已结算款项追偿的自动化 |

后台“中止与当期止付”“售后与仲裁”两个页面保留给周期结算上线前的历史订单；新订单统一走“服务中止与争议”。

## 2 角色与权限

| 角色 | 可做 |
| --- | --- |
| 会员（申请人） | 提交申请、补充材料、处理前撤回、在异议期内申诉 |
| 服务者 | 针对订单提交说明与图片、在异议期内对处理结果提出异议 |
| 公会管理者 | 仅在“先由公会处理”且服务者签约本公会时处理该申请 |
| 平台售后（总站） | 领取（记录处理人）、处理、复核、修改处理方式设置。申请人、处理人、财务执行人分离 |
| 站长 | 只读本站申请 |
| 代理 | 只收材料与升级，不处理申请，不冻结资金 |

## 5 主流程

1. **申请：**服务开始后（开始前请直接取消订单）→ 选择不达标原因 → 填写至少 10 字说明 → 可附图片 → 确认属实 → 创建申请。申请当天起的服务暂停，尚未结算的费用全部暂停结算。
2. **分流：**读取当前处理方式并保存到申请。
   - 直接由平台处理（默认）：进入平台处理。
   - 先由公会处理：服务者签约公会时进入公会处理（24 小时），否则进入平台处理。
3. **处理：**公会或平台在 24 小时内给出结果：退还全部未结算费用、部分退款（填写定价币种金额），或驳回（合作正常）。平台环节须先领取，或在处理时自动记录处理人。
4. **异议期（24 小时）：**
   - 会员可以申诉：对公会结果申诉转平台处理，对平台结果申诉转平台复核。
   - 服务者可以提出异议，路径相同。
   - 期满无人提出异议则执行。
5. **平台复核：**24 小时内完成，结果为最终结果，提交后立即执行。
6. **执行：**
   - 退款：从最后一个未结算服务日往前分配退款，按账单的 USDT 份额退回会员钱包（04 `TF-R006`、`TF-R022`）；其余未结算部分结算给服务者；服务终止。
   - 驳回：解除暂停，服务继续；暂停期间已到期的结算周期在下一次 00:00 照常结算。
7. **超时：**公会处理超过 24 小时，自动转平台；平台处理或复核超过 24 小时，标记超时并升级至平台主管（仍待处理）。

## 6 状态机

| 状态 | 进入条件 | 下一步 |
| --- | --- | --- |
| 公会处理中 | 先由公会处理，且服务者签约公会 | 处理结果 → 异议期；超时 → 平台处理中；会员撤回 → 已撤回 |
| 平台处理中 | 直接由平台处理，或公会超时，或对公会结果的申诉 / 异议 | 处理结果 → 异议期；还没有任何结果时会员撤回 → 已撤回；超时 → 标记升级 |
| 异议期 | 公会或平台给出非最终结果 | 申诉 / 异议 → 平台处理中（针对公会结果）或平台复核中（针对平台结果）；期满 → 执行 |
| 平台复核中 | 对平台结果的申诉 / 异议 | 复核结果 → 执行（最终） |
| 已退款 / 已驳回 / 已撤回 | 执行完成或撤回 | 结束 |

## 7 业务规则

- `AS-R001` 合作正常时不能无故取消或中止。申请必须选择不达标原因（服务者迟到或缺席 / 服务内容与约定不符 / 服务态度或言行问题 / 其他服务质量问题），并写至少 10 字说明。
- `AS-R002` 服务开始前不能申请中止，应直接取消订单（04 `TF-R011`）；费用已全部结算时不能申请。
- `AS-R003` 同一订单同时只能有一个处理中的申请；处理期间暂停结算，以及提交履约、确认、改期等操作。
- `AS-R004` 处理方式默认“直接由平台处理”（2026-10-06 确认），总站可改为“先由公会处理”，须填写依据；只对之后提交的申请生效，申请保存提交时的处理方式。
- `AS-R005` 每个处理环节时限为 24 小时（配置项）：公会超时自动转平台；平台超时标记并升级，案件仍保持待处理。
- `AS-R006` 每次非最终结果后有 24 小时异议期；会员申诉与服务者异议都须写至少 10 字理由，可附图片；平台复核结果为最终结果。
- `AS-R007` 退款金额不超过申请时尚未结算的金额；部分退款时，其余未结算部分结算给服务者。
- `AS-R008` 图片最多 3 张，限 png / jpg / webp / gif，大小受限；存放在私有存储桶，只能用短时效签名地址访问；保存期限按 D08。
- `AS-R009` 只有订单双方能提交说明与材料；有处理结果之前，会员可以撤回。
- `AS-R010` 所有处理动作记录处理人、依据和时间。已结算款项不在本流程的退款范围，如需退还，按追偿、协议抵扣或平台承担流程处理。
- `AS-R011` 举报不是裁决：受理、风险核查、处罚、独立申诉复核分别由不同岗位处理；第三方不能查询私聊证据。
- `AS-R012` 处理结果与退款以订单币种展示（首期为 USDT）。以后启用其他定价币种时，同时展示定价币种金额和 USDT 金额，USDT 金额按支付时的汇率快照计算，不随当前汇率变化。
- `AS-R013` 双方说明、证据与处理理由保持原文，不自动翻译。状态、按钮、通知模板按查看人的界面语言展示（07）。
- `AS-R014` 实物与订阅售后按 03 `CT-R010`、`CT-R011` 处理（售后窗口、退货收回、按比例退订），退款同样退回会员钱包。

## 8 异常与边界

- 处理期间服务者离开公会时，申请仍按保存的公会继续处理。
- 时间以服务器时钟为准；预发环境可以用“时间推进”验证时限，生产环境禁用。
- 并发提交处理结果时，以状态机校验当前状态，后到的请求被拒绝。

## 9 资金与证据影响

- 申请会冻结订单所有未结算金额（暂停结算），不冻结服务者其他订单的收益。
- 执行退款通过 04 模块的退款与钱包入账；分账和推广分红的冲减由 06 监听退款事件完成。

## 12 通知、待办与审计

- **待办：**公会（待处理申请）、服务者（提交说明、结果可异议）、会员（结果可申诉）、平台（待领取、超时）。通知按接收人的界面语言发送。
- **审计：**处理方式变更、领取、处理、复核、执行。
